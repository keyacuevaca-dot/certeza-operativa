# Robles · Propuesta de sitio web (Paso 1)

Documento de revisión de la propuesta para **Comercializadora Robles**: sistema visual, mapa del sitio, wireframes, dominios candidatos, datos conocidos y pendientes, matriz de fuentes y criterios de aceptación.

**Estado: borrador. No es el sitio final y no autoriza construir ni publicar nada.**

## Cómo abrirlo (en cualquier lugar)

`index.html` es un solo archivo autónomo: sin dependencias, sin conexión a internet y sin rastreadores.

- **En tu computadora o celular:** descarga `index.html` y ábrelo con cualquier navegador.
- **Desde GitHub:** abre el archivo en el repositorio y usa *Download raw file*. GitHub muestra el código, no la página.
- **Como página web:** cualquier servicio de páginas estáticas la sirve tal cual. Si el repositorio ya publica una página (por ejemplo, GitHub Pages), la propuesta quedará en `/robles-propuesta/` **solo después de unir esta rama a la rama publicada**. Hazlo únicamente si quieres que sea accesible por enlace.
- **Para guardarla en PDF:** ábrela en el navegador y elige *Imprimir → Guardar como PDF*; el estilo de impresión ya muestra todas las pestañas.

## Antes de compartirlo

El archivo contiene la dirección, el teléfono y el nombre del responsable del negocio. Lleva `noindex`, pero si el repositorio es público cualquiera con el enlace puede leerlo. Revísalo con el cliente antes de difundirlo.

No contiene datos bancarios ni fiscales del archivo CDR, y el CDR completo no está en el repositorio.
